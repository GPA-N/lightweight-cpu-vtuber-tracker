# Fallback model: karie666666/face-au-arkit-blendshapes

Scope: facts only, for OpenSpec change `cpu-face-tracking-spike`, task 1.6. No inference, no benchmark, no camera.

Not usable for the spike; private evaluation only, do not ship.

## Reproducing the checks

Each file was fetched with `curl -sL -o <name> https://huggingface.co/karie666666/face-au-arkit-blendshapes/resolve/main/<name>` into a new empty directory, then hashed with `sha256sum`. Nothing was executed. Graph metadata was read with `python -I` using `onnx` 1.23.2 (`onnx.load(path, load_external_data=False)`) in a separate venv. No onnxruntime session was created. `best_model.pt` was only scanned as bytes (`bytes.find`), never unpickled.
