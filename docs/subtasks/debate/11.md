# Debate 11: DX12 instead of Vulkan (env var only, no code)

## Hypothesis
Bevy logs `backend: Vulkan` on this AMD Ryzen 5 7430U iGPU. The backend choice is read from the environment: `bevy_render-0.19.1/src/settings.rs:84` calls `Backends::from_env()`, so `WGPU_BACKEND=dx12` should switch the backend with no code change.
- I think the window cost (bare window about 98 CPU points, subtask 07) is mostly Bevy's own render loop and the present/submit path, not the driver. Swapping the graphics API changes the driver's submit and present overhead, which is a small share of that.
- The research found no AMD evidence either way (bevy #24722 was NVIDIA). So my hypothesis: DX12 and Vulkan land within the 10 to 15 percent noise on CPU and memory on this GPU, with DX12 at most slightly lower.
- Cheaper explanation to watch for: the DX12 path may use more memory (D3D12 heaps) or a different swapchain, which would show as higher working set rather than lower CPU.

## Prediction
Live, 15 s, NO face, release build (the existing `target\release\live.exe`), alternating Vulkan and DX12, 3 pairs.
- Vulkan (6 runs): CPU average 85 to 110 %, peak working set 455 to 480 MB, peak private 845 to 880 MB, render 60 fps.
- DX12 (6 runs): CPU average 3 to 10 points below the Vulkan mean (about 80 to 105 %), peak working set 0 to 20 MB below the Vulkan mean, render 60 fps.
- KEEP threshold: all three DX12 runs beat all three Vulkan runs on CPU average or on peak working set by more than 15 percent (about 13 CPU points or about 70 MB). I predict this will NOT happen.
- What would prove me wrong: DX12 mean CPU more than 13 points below the Vulkan mean with the runs separated (then the driver path is a real cost and a KEEP is possible), or DX12 mean working set more than 20 MB above Vulkan (then DX12 costs memory), or a black, flickering or wrong avatar under DX12 (then DX12 is rejected on correctness regardless of numbers).
- Probe: `WGPU_BACKEND=dx12` must print `backend: Dx12`. If it prints Vulkan, the run stops and no code is touched.

## Result

## Verdict
Hypothesis WRONG. The backend matters a lot here. Under DX12 the CPU is about 4.2 times Vulkan (378.9 vs 90.9 points) and working set about 2.5 times (1108.6 vs 446.0 MB). The driver path is a real cost, not noise.
Prediction WRONG. I predicted DX12 3 to 10 points below Vulkan and 0 to 20 MB below. Falsifiers fired: DX12 working set more than 20 MB above Vulkan (about 660 MB above), and the screenshot failed (correctness, a stated falsifier).
KEEP rule: FAILS. DX12 is NOT kept. DX12 is also rejected on correctness: the MToon outline pipeline does not compile under FXC on this AMD iGPU (driver 31.0.21923.11000) and the avatar does not render.
REVERT: nothing to revert, no code was edited. Finding: do NOT set `WGPU_BACKEND=dx12`. Vulkan stays.
